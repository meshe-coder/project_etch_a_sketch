# Etch-a-Sketch

A small browser-based drawing app inspired by the classic Etch-a-Sketch. Choose a grid size, then click and drag across the board to draw by coloring cells.

## Features

- Create a square drawing grid by choosing a grid size that is a multiple of four.
- Draw by clicking and holding the left mouse button while moving across cells.
- Replace the current grid with a new one by choosing another size.
- Responsive layout with a retro-inspired drawing board.

## Run the project

Open `index.html` in a web browser. No installation or build step is required.

- JavaScript
